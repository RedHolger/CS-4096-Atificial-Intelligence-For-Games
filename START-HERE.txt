HOW TO OPEN
  1. Unzip into a NEW folder (do not unzip over an old copy).
  2. Unity Hub > Add > Add project from disk > pick OrchardOfTheLastSeason.
  3. Open it, press Play. No scene setup needed, the game builds itself.
  4. Check: the sidebar Shambler row must say "UTILITY AI · A*".
     If it says "Pathfinding (mud slows it)" you opened an old copy.
  5. Game view: Scale 1x for a sharp picture
     (menu Orchard > Make Game View Sharp does it for you).

CONTROLS
  WASD / arrows  move          Space  swing scythe
  F              pluck / catch Tab    show Shambler desirability bars
  Enter          start

MAP
  Trees always sit at least 2 cells from the edge, so they are never cut off.
  Each night 5 fallen logs lie across enemy paths. Shamblers and Stalkers must walk
  round them (A* re-plans); you, the dogs and the birds can cross them.

TREE REVIVE
  Fruit eaten by yellow birds (scatterlings) fills the "to revive a tree" bar.
  At 200 the tree that fell first comes back (gold glow, log: "Birds revived a tree!").
  Fruit you catch yourself counts as saved, but not toward the revive bar.
